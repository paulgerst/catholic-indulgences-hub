✝️ Catholic Indulgences API Documentation

Welcome developers! The Catholic Indulgences API provides structured, open-source JSON data based on the official Enchiridion Indulgentiarum (Manual of Indulgences). You can use this free endpoint in web apps, parish portals, and mobile applications.

---

1. Base Endpoints

You can fetch the complete dataset directly using either our primary GitHub Pages URL or the jsDelivr Global CDN:

Direct GitHub Pages Endpoint GET

GET https://paulgerst.github.io/catholic-indulgences-hub/data/indulgences.json

Fast CDN Endpoint (Recommended for Apps) GET

GET https://cdn.jsdelivr.net/gh/paulgerst/catholic-indulgences-hub@main/data/indulgences.json
---

2. Quick Start Example (JavaScript)

Fetch and log the indulgences in modern JavaScript using fetch():

// Fetch dataset from API
fetch('https://paulgerst.github.io/catholic-indulgences-hub/data/indulgences.json')
  .then(response => response.json())
  .then(data => {
    console.log("Total Indulgences Loaded:", data.length);
    console.log(data);
  })
  .catch(error => console.error("API Error:", error));
---

3. Data Schema & Response Fields

Each object in the returned JSON array contains the following fields:

Field Key Type Description
id String Unique slug identifier (e.g., marian-rosary-recitation)
title String Official title of the indulgence work or grant
type String Indulgence category: Plenary or Partial
norm_number String Canonical reference number in the Enchiridion
date_type String Timing rule: anytime, fixed_date, seasonal, or movable_feast
general_conditions Array List of standard spiritual requirements (e.g., Confession, Communion)
work_required String Specific pious work or prayer required to gain the indulgence
