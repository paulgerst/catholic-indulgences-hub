# ✝️ Catholic Indulgences Hub

An open-source database, calendar, and API for Catholic indulgences, based on the official *Enchiridion Indulgentiarum*.

---

## 📌 Project Overview
The **Catholic Indulgences Hub** is a central resource designed to help the faithful discover, search, and understand Catholic indulgences. This project provides a structured, open-source dataset along with tools for liturgical calendar tracking, search features, and embeddable widgets for third-party Catholic websites and ministries.

## ✨ Key Features
* 📖 **Comprehensive Database:** Structured records for plenary and partial indulgences.
* 📅 **Indulgence Calendar:** Special alerts and reminders for feast days and liturgical seasons.
* 🔍 **Search & Filter:** Easily filter by indulgence type, conditions, or dates.
* 🧩 **Embeddable Widgets:** Lightweight components for parish and webmaster integration.

## 📂 Repository Structure
* `/data` - JSON files containing indulgence records and conditions.
* `/widgets` - Embeddable JavaScript snippets and Web Components.
* `/docs` - Project documentation and API integration guides.

## 📜 Canonical Sources & Attributions
All norms, conditions, and prayer texts are sourced from canonical Catholic Church documents:
* *Enchiridion Indulgentiarum* (*Manual of Indulgences*, 4th Edition)
* Official translations and guidelines from the Holy See (Vatican) and episcopal conferences (e.g., USCCB).
